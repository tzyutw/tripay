# 常設檢查（C1–C14）

每一輪都要跑的檢查，用來擋「改 A 壞 B」。條文的定義與由來在 `_需求台帳.md` 的「常設」區，
這個資料夾是**跑得起來的那一半**。2026-11-05 依台帳重寫（原本的 `standing_C6.cjs`、
`standing_C13.cjs`、`copy_audit.cjs`、`conserve.mjs`、`acct_check.mjs` 存在暫時工作區、已遺失）。

## 怎麼跑

```bash
node 常設檢查/run-all.cjs
```

只跑某幾條：

```bash
node 常設檢查/run-all.cjs --only C4,C6
```

帶正式資料快照跑 C7／C8：

```bash
C78_SNAPSHOT=/某個暫存路徑/c78_snapshot.json node 常設檢查/run-all.cjs
```

- 會先建置量測靶（`vite build --mode harness` → `dist-harness/`），再用 Chromium 開 `harness.html` 量。
  已經建好可以設 `STANDING_SKIP_BUILD=1` 跳過。
- 報告寫到 `STANDING_OUT`（預設系統暫存區 `tripay-standing/`）：`report.md`（表格）、`report.json`（逐列明細）、
  `copy.json`（C14 這一輪的全站字串）。
- 結束碼：任何一條「沒過」→ 1。「跳過」「要人審」不算沒過。
- 全部跑完約 10 分鐘（C4 三種寬度 × 34 個狀態 × 靜態＋動畫取樣佔一半）。
- 需要 `npm ci` 過（用 repo 自己的 `puppeteer-core`、`esbuild`、`vite`）。Chrome 位置自動找，或設 `CHROME_PATH`。

### C7／C8 的正式資料怎麼拿（唯讀）

1. 用 Supabase MCP 的 `execute_sql`（或 SQL editor）跑 `C07_C08_唯讀匯出.sql`。整支只有一個 `SELECT`。
2. 把回傳的 `snapshot` 欄位存成 JSON 檔，**放在 repo 外**（這個 repo 是公開的）。
3. 設 `C78_SNAPSHOT=<那個檔>` 再跑。

快照不帶成員名字、email、備註、消費名稱——只有算帳要的數字，成員以「這趟裡的順位」表示。
腳本把 `src/lib/summary.ts` 與 `SettlementPage.tsx` 的 `breakdownFor` **原封不動打包**來跑，畫面怎麼算這裡就怎麼算。
沒給快照時 C7／C8 標「跳過」，不會假裝綠。

## 機器驗不到的（要人看、或要 Rozi 在手機上看）

| 條 | 驗不到的部分 | 為什麼 |
|---|---|---|
| C1 | 字母圓底的顏色好不好看、跟名字放在一起讀起來順不順 | 機器只驗得出「是不是同一套」，驗不出好不好看 |
| C3 | 白名單本身圈得對不對 | 白名單是指令寫的，腳本只負責比對 |
| C4／C5／C6 | iOS Safari 上的實際表現（原生日期框、聚焦放大、瀏海安全區） | 量的是無頭 Chromium。`input[type=date]` 這類原生控制項由作業系統排版，**要 Rozi 在手機上看過才算數** |
| C6 | 手指實際按起來順不順 | 只量得到幾何尺寸與遮擋 |
| C7／C8 | 用的是快照當下的資料；快照之後新記的帳要重新匯出 | 腳本不直接連正式資料庫（唯讀也不連），避免把金鑰放進腳本 |
| C10 | 「假資料的 title 若引用正式資料的名稱，形狀要逐欄相同」 | 正式資料快照刻意不帶消費名稱（隱私），這半條要人工對照 |
| C13 | 「分享給大家」在雲端無頭瀏覽器上可能落不到 `/share` | 2026-09-12 記過的環境差異；雲端量到紅要用真實 Chrome 對照一次再判 |
| C13 | 「就這樣結算」之後畫面真的變成已結算 | 樁的 Edge Function 回固定資料，只驗得到「真的依序送出 calculate → confirm」；結算後的畫面由 S-05 已結算那幾個狀態另外掃 |
| C14 | 句子讀起來順不順、會不會讓人誤會 | 機器只負責把「這一輪改了哪幾句」挑出來，三題要人回答 |

## 新增或修改檢查時

- 「查了但沒查到」與「沒有問題」在輸出裡要看得出差別：每條都印「掃到幾個」，並有數量下限。
- 比較式先斷言目標存在再比數值（`null < 54` 在 JS 裡是 true）。
- 新檢查要在 C11 加一隻金絲雀，證明它弄壞了會紅。
- 不要改 `src/` 與 `Tripay_原型.html` 來讓檢查變綠——這個資料夾只負責量。
