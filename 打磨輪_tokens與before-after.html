路線 3 打磨輪 · 第一段交付（v2，併入 Splitwise 參考分析）

一個工作色，兩個金錢色，明亮交給照片

Splitwise 的「明亮」不是來自元件用很多顏色，而是來自嚴格分工：UI chrome 只有一個工作色， 金錢只有兩個方向色，情緒全部交給大面積內容區。Tripay 照這個結構走，但**明亮由真實旅行照片承擔**， 不是插畫。

字體規則修正（Rozi 2026-08-31）：等寬（IBM Plex Mono）只用於金額。 日期、天數、筆數等其他數字一律用 PingFang TC（需要對齊時只加 tabular-nums，不換字體）。 等寬字是「這是錢」的訊號，用在別處就把訊號稀釋掉了。
上一版被推翻的兩件事： ① accent #D2764A 是 AI 模板陶土橘。 ② 我改的「收據紙 #F1F0EA」距離模板米色 #F4F1EA 只有 3.2—— 等於沒改掉。這一版底色推到 #EDEEE8（距離 7.9、近中性偏綠），才真的離開那個色帶。
合併兩份指令後浮出的撞色：上一版的「印泥朱砂 #9E3A2F」色相 6°， 而金錢方向色「要給出」是 10°——相距 4°，等於同一個顏色兩種語意。 朱砂因此退場，那個色相讓給金錢。狀態章改用工作色描邊（章不一定要是紅的）。

Typography

不載中文 webfont，個性放在紀律與數字

不載任何中文 webfont。標題與內文都用 PingFang TC（fallback Noto Sans TC）， 省掉數 MB 的字檔，也避開「繁中襯線只有一個選項」這件事本身就會讓成品長得跟別人一樣。 整站個性由字階、字重紀律與等寬數字承擔——唯一載入的 webfont 是數字用的 IBM Plex Mono。 不用圓潤幾何無襯線（Poppins 系＝Splitwise 皮）。

Structure

結構原則

一色工作原則

所有可點擊的東西同一個工作色。現況的 primary＋各狀態色全部收斂。

金錢方向色

綠＝可拿回、橘紅＝要給出，用於結算頁、分享頁、行程內頁統計區。 首頁行程卡不顯示金額（路線 2 決策）。其餘文字一律中性。

大色塊 header

行程內頁沿用照片卡的容器——滿版目的地色／照片＋白字標題，就是首頁卡的內頁版。

chips 次級導覽

結算／統計／分享／匯出收成一排 chips，取代散落的按鈕。

台幣／外幣切換

行程內頁保留現行的雙幣切換，整頁一致（項目＋統計同步換）。結算恆為台幣。

危險動作用色

刪除行程／刪卡不用金錢橘紅，改用中性深灰底＋橘紅文字， 避免與「要給出」混淆。破壞性確認鈕才填滿橘紅。

圓角兩種、陰影兩層

3px 卡片與輸入框、999px 僅 chips 與頭像。列表列用 1px 邊框，不用陰影。

emoji 只給人與封面

成員、行程封面、消費分類保留。介面 icon 不用 emoji，狀態章上的 ✅ 已移除。

Signature

一處就好：結算送出的那一刻

Splitwise 的消費 icon 是鋸齒底收據——證明收據語彙在分帳領域成立。 Tripay 的 Logo E（收據摺成紙飛機）可以比它走得更遠：不只是一個 icon，而是一個動作。

整站只在一個時刻用它：按下「算清楚」到結果出現的那幾百毫秒—— 統計卡沿中線收摺、往上送出，落下變成結算結果。把一疊帳摺起來寄出去，正是結算在做的事。

其他地方安靜：沒有全站 fade、沒有 hover 彈跳、沒有票根撕孔。 prefers-reduced-motion 時直接跳結果。

品質門檻（Rozi 2026-08-30 訂）：必須讀得出「一疊帳摺起來 → 寄出去」的兩段敘事， 實作用 CSS 3D transform 分步摺疊（rotateX 沿摺線收合 → 成形 → 送出）， 不是 icon 傾斜再彈回。
Aria 審查若判定達不到門檻，直接退回乾淨的一般 loading （進度圈＋「正在算清楚…」），不保留半吊子動畫。
