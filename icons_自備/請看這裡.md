# 自備 icon 放這裡

想換掉某個 icon，就把 SVG 檔放進這個資料夾，**檔名照下表命名**。
只放你想換的就好，沒放的維持原樣。放完在對話裡跟我說一聲。

## 檔名對照表

檔名就是左欄那個字，加上 `.svg`。例如返回鍵就存成 `back.svg`。

| 檔名 | 現在畫的是 | 用在哪裡 |
|---|---|---|
| `back.svg` | 返回 | 各頁左上角的返回鍵 |
| `next.svg` | 進入下一層 | 設定頁每一列右邊的箭頭、可點進去的列 |
| `down.svg` | 展開 | 統計卡「查看計算依據」、結算頁展開鍵（收合時） |
| `up.svg` | 收合 | 同上（展開時） |
| `edit.svg` | 編輯 | 編輯行程入口 |
| `copy.svg` | 複製 | 複製分享連結／文字摘要 |
| `share.svg` | 分享 | 行程頁右上角的分享 |
| `settings.svg` | 設定 | 行程頁右上角的齒輪 |
| `add.svg` | 新增 | 記一筆、新增行程 |
| `del.svg` | 刪除 | 刪除這趟行程、刪除這筆 |
| `check.svg` | 完成／已付清 | 標記付清、確認 |
| `warn.svg` | 提醒 | 「還沒算清楚」「還沒填」的提示 |
| `close.svg` | 關閉 | 彈窗右上角的 ✕ |

**目前就這 13 個**，全站沒有第 14 個 icon。
（程式裡另外有 `filter` 和 `money` 兩個定義，但全站沒有用到，會一併清掉，不用理它們。）

## SVG 要注意的事

**你要顧的只有這三件**：

1. **檔名要對**（照上表）。
2. **一個檔案一個圖示**，不要把整組拼在一張 SVG 裡。
3. **單色**。不要用兩種以上的顏色來區分結構——我們會把整個圖示統一成一個顏色，
   多色的圖示轉過來會糊掉。

**這些我來處理，你不用管**：

- 顏色（不管你存成什麼顏色，都會統一換成跟著文字走的顏色）
- 尺寸與 `viewBox`（不是 24×24 也沒關係，會換算）
- 線條粗細、端點圓角（會統一成全站一致）

**這些請避免**：漸層、遮罩、內嵌點陣圖、文字圖層、外部字體參照。
如果原檔有這些，請先在 Illustrator／Figma 裡「外框化」再匯出。
