## 修-8　「分享給大家」要接上既有的分享 sheet，不是回到行程頁

**Rozi 回報**：「『分享給大家』這個按鈕不能按」。

**Cowork 實測**（量測靶 `?screen=s05&state=done`）：按鈕**按得到**——可點區 362×45、中心打到自己、
沒有 disabled——按下去之後 **URL 不變、畫面跳回行程詳情頁**（「2026 濟州島四寶團／消費／結算／總花費…」），
**沒有開任何分享畫面**。她說的「不能按」＝按了畫面跳走、看不到分享。

**原因**：`src/pages/SettlementPage.tsx:581`
```tsx
<button className="btn" onClick={() => navigate(`/trips/${tripId}`)}>分享給大家</button>
```
導向的是行程頁本身。而分享 sheet 走的是 `/trips/${tripId}/share`
（`ExpenseListPage.tsx:384` `onShare={() => navigate(`/trips/${tripId}/share`)}`、`:350` `shareSheetOpen = location.pathname.endsWith('/share')`）。

**依據**（不是「既有 bug」四個字帶過）：`Tripay_原型.html:3137` S-05-29「結算完成分享 CTA：『把結果傳給大家／任何人免登入可看』」
——這顆按鈕的規格就是**分享**，不是「回行程頁」。實作跟原型不一樣，屬 A 類（實作沒接上原型）。

**改法**：只改那一行的目的地：
```tsx
onClick={() => navigate(`/trips/${tripId}/share`)}
```
**移植檢查**：接上 S-03 既有的那個分享 sheet，**不准另寫一個分享畫面**。
如果 `/share` 路由在 S-05 底下開不起來（sheet 是掛在 S-03 的元件裡），
那就先 `navigate(`/trips/${tripId}/share`)` 讓 S-03 帶著 `/share` 開，**確認 sheet 真的彈出來**再算數。

⚠️ **文案不動**：原型寫「把結果傳給大家」、實作寫「分享給大家」，兩邊不一致，
但「分享給大家」是 Rozi 已經看過沒抱怨的，這一輪不改字，記進 `_延後與不做清單.md` 給她決定。
