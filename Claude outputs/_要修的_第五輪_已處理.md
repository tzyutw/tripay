## ① 🔴 記一筆的彈出頁被裁掉，「取消／記下來」按不到

**重現**：任一行程 → 記一筆 → 往下捲。**捲不動**，畫面停在「1 人均分 · 每人 —」。
底下的「這筆是 / 贊助／回饋 / 取消 / 記下來」看不到也按不到。

**實際量到的數字**（視窗 533×680）：
```
sheet.scrollHeight = 837   sheet.clientHeight = 646   →  被裁掉 191px
overflow-y = hidden        「記下來」按鈕 top=809 bottom=855，viewport 只有 680
```
**在 Rozi 的 iPhone（844 高）上一樣會發生**：`max-h-[95%]` ≈ 801，內容 837 → 仍然溢出，
「記下來」被切掉。

**根因（一處）**：`src/components/ExpenseFormSheet.tsx:291`
```jsx
<div className="sheet relative shadow-sheet max-h-[95%] flex flex-col animate-sheet-up overflow-y-auto scrollbar-hide">
```
`.sheet` 在 `src/index.css:294` 是 `overflow:hidden`，跟同一個元素上的 `overflow-y-auto` **打架**，
`overflow:hidden` 贏 → 整張不能捲。

**正確做法就在隔壁檔案**：`TripFormSheet.tsx:403,418` 是對的——
外層 `max-h-[93%] flex flex-col`（**不帶 `.sheet`、不捲**），
內層 `<div className="flex-1 overflow-y-auto scrollbar-hide …">` 放內容，
footer（取消／記下來）**放在捲動區外面**，所以永遠按得到。

**要做的**：把 `ExpenseFormSheet` 改成跟 `TripFormSheet` 同一個結構。
不要只是把 `.sheet` 拿掉了事——footer 必須在捲動區外，否則內容一長還是會被推出去。

**停止條件**：
1. 新測試：render 記一筆，斷言
   `sheet.scrollHeight <= sheet.clientHeight + 1`
   **且**「記下來」按鈕的 `getBoundingClientRect().bottom <= window.innerHeight`。
   反向驗證：把 `overflow-y-auto` 加回外層 → 這條要紅。
2. `實作_版面回歸測試.cjs` 補一條：s04 開啟記帳 sheet 後，
   **sheet 的 footer 按鈕必須在 viewport 內**（不是只量 scrollWidth）。

## ② 🔴 沒選付款人時按「記下來」完全沒反應，也沒有任何提示

**重現**：記一筆 → 填標題與外幣金額 → **不要點「誰付的？」的人** → 按「記下來」。
**什麼都不會發生**：sheet 不關、沒有錯誤訊息、`POST /rest/v1/expenses` 連發都沒發
（我查了 Supabase 的 edge log，那段時間沒有任何 POST）。
選了付款人之後再按，就正常存檔並跳出「已存。這筆金額還沒填…」。

**問題不是「不能存」，是「靜默失敗」**：按鈕看起來可以按（`disabled` 是 false），
按下去卻什麼都不說。使用者只會覺得「這個 App 壞了」。

**要做的**：付款人沒選時，比照其他欄位在「誰付的？」下面出現一行錯誤
（用現有的 `.err` 樣式與 `errors` 機制，不要另寫一套），並把焦點捲到那一列。
文案照現有語氣，例如「先選這筆是誰付的」。

**停止條件**：測試：不選付款人按「記下來」→ 畫面出現該錯誤字串、且 `onSubmit` 沒有呼叫 insert；
選了之後再按 → 錯誤消失且有呼叫。反向驗證：拿掉檢查 → 要紅。
